# ATF V-2.1 Edge-Processed SHM Node
## 17. Glossary and References

This document provides a comprehensive glossary of all technical terms, mathematical symbols, academic and industry references, and a document cross-reference index used throughout the ATF V-2.1 Structural Health Monitoring (SHM) Node project documentation. 

---

### 1. Glossary of Terms

| Term | Definition |
|------|------------|
| **ADC (Analog-to-Digital Converter)** | Hardware that converts continuous analog signals to discrete digital numbers. The HX711 provides a 24-bit ADC specifically for strain measurement. |
| **AE (Acoustic Emission)** | High-frequency stress waves generated by the rapid release of energy from localized sources within a material, such as micro-crack growth. |
| **BPA (Basic Probability Assignment)** | In Dempster-Shafer theory, a function assigning belief masses to subsets of a frame of discernment. *(Phase 2 Stretch Goal)* |
| **Changepoint Detection** | Statistical methods for identifying points in a time series where the statistical properties (such as mean or variance) change abruptly. |
| **Covariance Matrix** | A square matrix giving the covariance between each pair of sensor channels, used in Mahalanobis distance computation for fault detection. |
| **CUSUM (Cumulative Sum)** | A sequential changepoint detection algorithm that accumulates deviations from a reference value to detect shifts in the process mean. |
| **CWT (Continuous Wavelet Transform)** | A signal analysis method that decomposes a signal using dilated and translated versions of a mother wavelet, providing a time-frequency representation. |
| **Daubechies Wavelet** | A family of orthogonal wavelets with compact support, named after Ingrid Daubechies. The db4 and db6 wavelets are commonly used for transient detection in our system. |
| **Dempster-Shafer Theory** | A mathematical theory of evidence that allows the combination of evidence from different sources with explicit representation of uncertainty and conflict. *(Phase 2 Stretch Goal)* |
| **DWT (Discrete Wavelet Transform)** | A computationally efficient wavelet transform using discrete scales and translations, implemented via Mallat's filter bank algorithm. |
| **Edge Computing** | Processing data locally on the device (the node itself) rather than transmitting all raw data to a cloud server for processing. Reduces bandwidth and latency. |
| **Elastic Deformation** | Temporary structural deformation that fully recovers when the applied load (e.g., traffic on a bridge) is removed. Not structurally dangerous. |
| **ESP-IDF (Espressif IoT Development Framework)** | Official development framework for the ESP32 series microcontrollers. |
| **ESP32-S3** | Dual-core Xtensa LX7 microcontroller with vector instructions for ML/DSP, 512KB SRAM, and WiFi/BLE, manufactured by Espressif. |
| **FFT (Fast Fourier Transform)** | Algorithm to decompose a signal into its constituent frequency components. Good for analyzing stationary signals, but poor for transients like acoustic snaps. |
| **FreeRTOS** | Real-time operating system for microcontrollers, providing task scheduling, synchronization, and timing services across the dual-core architecture. |
| **Gauge Factor (GF)** | Ratio of the relative change in electrical resistance to mechanical strain in a strain gauge. Typical value: 2.0 for metal foil gauges. |
| **HX711** | 24-bit precision ADC designed for weigh scales and strain gauge applications, featuring a built-in programmable gain amplifier (PGA). |
| **I2C (Inter-Integrated Circuit)** | Two-wire serial communication protocol used for connecting low-speed sensors (e.g., BME280, MPU6050/BNO085). |
| **IMU (Inertial Measurement Unit)** | Sensor combining an accelerometer and gyroscope to measure orientation, acceleration, and angular velocity, used for structural tilt monitoring. |
| **INT8 Quantization** | Reducing neural network weights and activations from 32-bit floating-point numbers to 8-bit integers, significantly reducing model size and inference time on tiny edge devices. |
| **IP65/IP67** | Ingress Protection ratings for enclosures. IP65: dust-tight, protected against water jets. IP67: dust-tight, protected against temporary immersion. |
| **ISR (Interrupt Service Routine)** | A function executed in response to a hardware interrupt (such as an acoustic comparator trigger). Must be fast and minimal. |
| **LoRa (Long Range)** | Low-power, wide-area network protocol designed for IoT, operating in unlicensed ISM bands (865-867 MHz in India). Range can be up to 15km. |
| **Mahalanobis Distance** | A multivariate distance measure that accounts for correlations between variables and differing variances. Used to detect anomalies and discriminate between sensor faults and structural faults. |
| **Mallat's Algorithm** | An efficient algorithm for computing the DWT using cascaded low-pass and high-pass filters coupled with downsampling. |
| **Microstrain (µε)** | Unit of strain equal to 10⁻⁶. Typical elastic strain observed in a concrete bridge under traffic is 50-200 µε. |
| **MPPT (Maximum Power Point Tracking)** | A circuit that optimizes power extraction from solar panels under varying light and environmental conditions. |
| **NRE (Non-Recurring Engineering)** | One-time design, development, and tooling costs (e.g., PCB layout, 3D modeling) that do not repeat per manufactured unit. |
| **NVS (Non-Volatile Storage)** | ESP32 flash memory partition for storing key-value pairs that must persist across deep-sleep reboots (e.g., learned thermal calibration coefficients). |
| **OTA (Over-The-Air)** | Method of remotely updating node firmware or ML models once the device is deployed in the field. |
| **Page-Hinkley Test** | A sequential changepoint detection algorithm that accumulates evidence of a permanent shift in the mean of a time series, utilized to evaluate strain drift. |
| **Plastic Deformation** | Permanent deformation that does not recover when the applied load is removed. Strongly indicates structural damage. |
| **PSRAM (Pseudo-Static RAM)** | External RAM attached to some ESP32-S3 modules, providing additional memory (typically 8MB) beyond internal SRAM to support larger ML operations or buffering. |
| **R² (Coefficient of Determination)** | Statistical measure representing how well regression predictions fit the actual data. An R² of 1.0 represents a perfect fit. Used in thermal compensation modeling. |
| **SHM (Structural Health Monitoring)** | The process of implementing a damage identification and monitoring strategy for engineering infrastructure, such as concrete highway bridges. |
| **SPI (Serial Peripheral Interface)** | Full-duplex serial communication protocol used for high-speed, short-distance communication, particularly with the LoRa transceiver. |
| **SX1278** | Semtech LoRa transceiver IC operating in the 137-525 MHz frequency range (configured for 865-867 MHz India ISM), commonly used for long-range IoT networks. |
| **TFLite Micro (TensorFlow Lite for Microcontrollers)** | Lightweight machine learning inference engine designed to execute models on microcontrollers with severely constrained memory. |
| **TinyML** | Machine learning inference running on ultra-low-power microcontrollers, characterized by milliwatt-level power consumption. |
| **TP4056** | Linear Li-ion battery charger IC with built-in overcharge and overdischarge protection circuitry. |
| **Wavelet Transform** | A mathematical transform that decomposes a signal into components at different scales (frequencies) while precisely retaining time information (unlike FFT). |
| **Wheatstone Bridge** | A circuit of four resistors used to precisely measure very small changes in electrical resistance (from a strain gauge) by detecting voltage imbalances. |
| **WPC (Wireless Planning and Coordination Wing)** | Indian government body responsible for frequency spectrum management and type approval of radio equipment. |

### 2. Mathematical Symbols

| Symbol | Meaning | Context |
|--------|---------|----------|
| $\psi$ | Mother wavelet function | Wavelet Transform (Acoustic) |
| $a$ | Scale parameter (inversely related to frequency) | Wavelet Transform (Acoustic) |
| $b$ | Translation parameter (time shift) | Wavelet Transform (Acoustic) |
| $d_j[k]$ | Detail coefficients at decomposition level $j$ | Discrete Wavelet Transform |
| $E_j$ | Energy at decomposition level $j$ | Wavelet energy thresholding |
| $\delta$ | Allowance parameter (minimum detectable shift magnitude) | Page-Hinkley Changepoint Detection |
| $\lambda$ | Detection threshold | Page-Hinkley Changepoint Detection |
| $PH_n$ | Page-Hinkley test statistic at sample $n$ | Page-Hinkley Changepoint Detection |
| $\beta_0, \beta_1$ | Regression coefficients (intercept, slope) | Thermal Environmental Calibration |
| $R^2$ | Coefficient of determination | Regression validation (Thermal) |
| $\boldsymbol{\mu}$ | Mean vector of sensor readings | Mahalanobis Distance (Faults) |
| $\Sigma$ | Covariance matrix | Mahalanobis Distance (Faults) |
| $D_M$ | Mahalanobis distance | Sensor-fault vs. Structural-fault discrimination |
| $\chi^2$ | Chi-squared distribution | Mahalanobis threshold determination |
| $\epsilon$ | Strain (deformation per unit length) | Strain measurement |
| $E$ | Young's modulus (material stiffness) | Beam deflection *(Phase 2)* |
| $I$ | Second moment of area (cross-section geometry) | Beam deflection *(Phase 2)* |
| $m(A)$ | Basic probability assignment for proposition A | Dempster-Shafer Theory *(Phase 2)* |
| $Bel(A)$ | Belief function for proposition A | Dempster-Shafer Theory *(Phase 2)* |
| $Pl(A)$ | Plausibility function for proposition A | Dempster-Shafer Theory *(Phase 2)* |
